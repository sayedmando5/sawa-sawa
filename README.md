# سوا سوا 3 — سيد وجنة

تطبيق عربي RTL: 630 كارت فريد في 34 قسمًا، و14 لعبة، وجولات مخصصة، وحفظ محلي، وواجهة حسابات ومزامنة بيانات مشتركة عبر Supabase.

**اقرأ ONLINE-START.md قبل التسجيل والنشر.** يوضح بالضبط ما تم تنفيذه، وعائق النشر الحالي، وقيود إرسال بريد التأكيد.

## التشغيل المحلي

```bash
python -m http.server 3000
```

افتح http://localhost:3000. لا dependencies لتشغيل التطبيق، ولا build. تجنب فتح index.html مباشرة من file://؛ استخدم خادمًا محليًا.

## ما يعمل محليًا

- 630 نص كارت فريدًا، منها 60 كارت مواقف (20 موقفًا × 3 زوايا نقاش).
- 34 قسمًا، مع إخفاء قسم القرب افتراضيًا.
- 14 لعبة: حقيقة/تحدي، لو خيروك، مين فينا، تعرفني قد إيه، العجلة، خمس حاجات، مساحة اتفاق، قصة، ترتيب، ممنوع تقول، توقّع، حقيقتين وكدبة، أول كلمة، وأحلامنا الصغيرة.
- جولات من 6/12/24 كارت حسب المزاج، وسحب بدون تكرار داخل دورة القسم، وأولوية للجديد في الجولات المخصصة.
- منافسة فردية، أو نقاط فريق، أو بلا نقاط.
- ذكريات وكوبونات ومفضلة وأحلام وملاحظات ورسائل مستقبلية محلية، وتصدير/استيراد.
- اسم جنة يتنوع حسب السياق: جنة الله وجنة وجنة سيد نفس الشخص، وسيد هو الطرف الآخر.

## ما أضيف للأونلاين

- دخول بكلمة مرور، إنشاء حساب، استعادة كلمة المرور، وتأكيد البريد.
- مساحة لحسابين ودعوة عشوائية أحادية الاستخدام لمدة 24 ساعة.
- مزامنة الذكريات والكوبونات والأحلام والمفضلة المشتركة والملاحظة، كل سجل على حدة.
- رسائل مستقبلية لا يعيد الخادم نصها قبل موعد الفتح.
- revision لكل عنصر، وتعارضات صريحة بدل استبدال صامت، ومسودات محلية عند تعذر الاتصال.
- تحديث تلقائي كل 6 ثوانٍ أثناء فتح الصفحة.

## ما لم يكتمل بعد

- لم يتم نشر الموقع بنجاح على Vercel. تم إنشاء المشروع فقط، ورفض موصل النشر الحقل الناقص projectSettings. تحتاج أول عملية نشر من لوحة Vercel/ربط Git.
- لم يتم ضبط SMTP مخصص أو اختبار وصول رسائل تأكيد إلى حسابيكما الحقيقيين.
- اللعب المتزامن بين جهازين، الأدوار السرّية المشتركة، ومزامنة النقاط والجولات ليست مضافة. الألعاب الحالية محلية حتى عند تفعيل الحساب المشترك.
- لا Push، لا APK، لا رفع صور، ولا PWA مكتملة دون اتصال.
- لا تشفير طرف لطرف، ولا ادعاء أن المحتوى لا نهائي.

## إعدادات عامة وليست أسرارًا

cloud-config.js يحتوي رابط المشروع ومفتاح Publishable فقط. لا كلمات مرور أو مفاتيح خادم في الملفات.

قاعدة Supabase مهيأة فعليًا بصلاحيات RLS ودوال الكتابة والعضوية. لا تنفذ سياسة using(true) القديمة. لا تشارك ملفات نسخ بياناتكم الاحتياطية في GitHub.

## النشر

الحزمة كلها ملفات ثابتة. ارفع الملفات إلى جذر مستودع GitHub، ثم اربطه بمشروع Vercel sawa-sawa واختر Other بلا أوامر build أو install. index.html يجب أن يكون في الجذر. تعليمات ويندوز التفصيلية في ONLINE-START.md.

## المطور

- content.js وexpansion-content.js وextra-cards.js: المحتوى.
- app.js وexpansion.js: التطبيق والألعاب والحفظ المحلي.
- cloud-config.js: إعدادات العميل العامة.
- online.js: المصادقة، العضوية، المزامنة، الرسائل المقفولة، وفصل الحساب عن البيانات المحلية.
- style.css: التصميم المتجاوب.
- vercel.json: ترويسات أساسية فقط؛ لا rewrites أو اعتماد على Storage لملفات البرنامج.
